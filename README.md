## 🕐 Analog Digital Clock & Date

A simple and interactive Analog + Digital Clock with Date built using HTML, CSS, and JavaScript.

This project was created as part of my JavaScript practice to improve my understanding of DOM manipulation, JavaScript Date objects, CSS styling, and real-time updates.

## ✨ Features
- 🕐 Analog Clock with moving hour, minute, and second hands
- 🕒 Digital Clock displaying the current time
- 📅 Current Date display
- 🔄 Real-time clock updates
- 📱 Simple and responsive design
- 🎨 Clean and minimal UI
- 🛠️ Technologies Used
- HTML5 — Structure of the application
- CSS3 — Styling and clock design
- JavaScript — Clock functionality and real-time date/time updates
